# 问象 · 占卜 · DSH 插件

版本 `0.6.0`，针对 **DeepSeek Harness 桌面端 0.2.0-rc.2**。星空门户通往梅花易数、塔罗、小六壬、雷诺曼与六爻纳甲五个模块。各体系保留独立本地规则与结果，五模块跟随宿主深浅主题，复用 DSH 已配置的供应商及模型，定位为闲时娱乐与自省。

## 安装与使用

安装包位于 `artifacts/dsh-meihua-0.6.0.tgz`。技术包名、既有梅花接口与扩展服务保持兼容。

1. 在 DSH 左侧打开「插件」，选择「添加插件」。
2. 将安装包的**绝对路径**粘贴到安装来源输入框；按 DSH 的安装流程安装并启用。
3. 左侧打开「问象 · 占卜」，在星空中选择任一占卜模块。进入约 1.6 秒、返回约 0.8 秒，可跳过；减少动态效果模式采用快速切换。
4. 梅花可选时间或三数起卦，约 4.8 秒仪式后查看本卦、互卦、变卦、动爻、体用、五行和计算过程。
5. 塔罗填写问题、选择牌阵和是否包含逆位，洗牌后从 78 张背牌中依次手选。选满后顺序翻牌或全部揭示，查看本地牌义，点击牌面可放大。
6. 选定已配置的供应商与模型，主动点击「开始解读」。每次占卜保留一份初始解读；初始解读已有文字且生成结束后可围绕该结果连续追问，沿用首次所选模型。取消、出错或截断保留已收到文字，不自动重试。生成中需先取消才能使用插件内导航。
7. 可分别复制各模块的当前结果和全部问答。门户往返和宿主页面切换保留本次运行的草稿、结果与进度；另起一轮只替换对应模块。

CLI 安装示例（已配置 `dsh` 命令时）：

```sh
dsh plugin add /absolute/path/dsh-meihua-0.6.0.tgz --profile desktop
```

普通安装包不带模拟供应商。正常解读会调用你选择的供应商，并按其规则产生费用。开页面、起卦、抽牌、翻牌和查看基础牌义不调用模型，也不加载远程图片或字体。

## 共享背景与独立口令

从门户或任一占卜模块打开「共享背景」，首次设置至少 8 字符的独立口令。生日、出生时间、地点、近期处境与偏好直接写入这一份文档；上限 4000 字符，手动新增或修改的段落固定保留。文档、最近 20 个版本及新版私人问询记录都由 Host 的唯一 MemoryService 管理，以 AES-256-GCM 密文保存到宿主 JSON storage；口令经异步 scrypt（N=131072、r=8、p=1）派生包装密钥，改口令只重新包装随机数据密钥。客户端不使用 localStorage 保存个人内容。

解锁在本次宿主启动期间有效。手动锁定会取消私人内容生成，清理各模块当前会话与解密缓存；重启宿主后需重新解锁。锁定期间仍能起卦、抽牌、翻牌与查看本地释义，AI 解读和自动提炼需要解锁。忘记口令无法恢复资料，请自行妥善保管。

每次新解读默认引用当前共享背景；可以取消「本次使用共享背景」。选择「替他人占卜」同时停用本人背景引用与自动记忆写入。首次 AI 解读开始时冻结背景版本，后续追问沿用该快照；手动编辑或另一模块生成的新背景只影响下一次新解读。背景以用户资料块传入模型，不能覆盖固定卦象、牌阵或系统规则。

点击「结束本轮并更新背景」、离开当前模块或另起一轮时，只处理尚未提炼的用户问题与追问；宿主暂时切走、刷新或重新打开页面不触发提炼。没有新增消息不调用模型。提炼使用本次所选模型，未选模型时显示待更新；新增事实必须有用户原文依据，助手预测、假设、引用与第三方经历不写成本人事实，日期和“不详”等限定保持原文。明确矛盾的资料标为待核实。摘要失败、取消、不合格或晚于手动修改时保留旧版，不自动重试；可以显式再次点击结束更新。

每次成功更新保存一个版本，可查看更新前后内容并恢复旧版本；恢复产生新版本，已经处理的消息不会在下一次结束时再次写回。模块切换可以在后台提炼，下一次 AI 解读会等待更新结束再冻结最新成功版本。清空全部私人资料会取消在途任务、清除文档、版本、关联加密记录与各模块当前缓存，并使旧页面提交失效。

加密保护本地持久化内容。AI 解读与自动提炼仍将相关明文发送给所选模型供应商；插件省略私人生成请求的 sessionId，避开本次核实的 DeepSeek Session 日志贡献器，但不承诺隔离所有宿主插件或供应商。旧版已经写出的普通日志不自动迁移或删除。首版无云同步、多人物档案、向量数据库或完整历史列表。

## 小六壬、雷诺曼与六爻纳甲（0.6）

小六壬按农历月、日、时在大安、留连、速喜、赤口、小吉、空亡六位顺数，显示月宫、日宫与最终时宫、本地释义及逐步计数。闰月同数、当地零点换日；指定时间按配置时区解释。古本“三月初五辰时得小吉”与日期边界已独立对照，完整约定见 `docs/g5-xiaoliu-rules.md`。

雷诺曼使用标准编号 1—36 的小牌组和本项目原创 SVG 素材，提供三张/五张连读，无逆位。Host 安全随机洗牌，按点击背牌的顺序绑定位置，抽取不重复；选满后揭示整组牌，显示中牌主题、相邻组合与五张排列的两组镜像。本地中文释义和方向性组合规则独立编写，详见 `docs/g6-lenormand-rules.md`。所有 36 张素材均本地内嵌，MIT 许可和逐张 SHA-256 随包保存。

六爻按自下而上的六次三币和值装卦：字面 2、背面 3，6 老阴、7 少阳、8 少阴、9 老阳。可模拟投币，也可记录实物和值；多动爻共同生成变卦。结果完整展示本变卦、八宫与世应、每爻纳甲、六亲、六神、月建、日辰与旬空。月建按节气交接时刻计算；日辰按当地民用零点换日，不采用晚子时提前换日或真太阳时。离线历法使用固定版本 `lunar-javascript 1.7.7` 的未修改源码及 MIT 许可。2026 十二节已与香港天文台分钟精度数据对照；完整人工例盘、传承约定和精度范围见 `docs/g7-liuyao-rules.md`。

三个新模块共用共享背景、流式显示、取消和冻结追问。复制包含本地完整结果、尚未完成的投币/选牌过程、模型、背景版本及全部问答；不复制后台隐藏牌组或背景文档正文。内置模块接入契约见 `docs/g4-module-framework.md`，`dsh-meihua/xiaoliu`、`dsh-meihua/lenormand` 与 `dsh-meihua/liuyao` 提供可独立使用的纯规则导出。新增认证命名空间对应 `/api/xiaoliu/*`、`/api/lenormand/*`、`/api/liuyao/*`，所有私人变更仍携带当前记忆 epoch。

G8 交付固定《关圣帝君灵签》100 签校勘内容包与独立模块施工规格；G9 交付八字、占星、奇门和卢恩各自的需求、规则样例、依赖、成本及实施计划。内容包在 `content/lot/guandi-100`，研究和工程规格在 `docs/g8-*`、`docs/g9-*`；它们尚未作为可用占卜入口安装，不自动增加命盘个人资料表单。

## 塔罗规则与素材

完整经典 Rider–Waite–Smith 牌组：22 张大阿卡纳与权杖、圣杯、宝剑、星币各 14 张。四种牌阵：单张指引（1）、时间之流（3，过去/现在/未来趋势）、问题剖面（3，现状/阻碍/建议）、凯尔特十字（10）。十字固定为现状、阻碍、目标与可能、基础、过去、近期发展、自身立场、环境影响、希望与恐惧、发展趋势，不另抽指示牌；第 2 张横置属于布局，正逆位独立记录。

Host 用 `crypto.randomInt` 驱动 Fisher–Yates 洗牌。牌序和正逆位在开始时冻结；开启逆位时每张独立 50% 概率，关闭时全部正位。选取的背牌位置按点击顺序绑定牌位，不能重复。未揭牌面和方向不通过 RPC 返回，重开客户端仍恢复选牌/翻牌进度。问题和动画不影响随机结果，模型不参与抽牌。

78 张历史 Pam-A 牌面来自同一 [TaionWC 扫描集](https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC))，逐张记录 Commons 的 Public domain 声明、作者、原文件与处理后哈希，见 `src/assets/tarot/assets-sources.json`。图像统一为 576×960 WebP，保持比例和完整绘画/英文牌名，并以 data URI 随客户端打包；发行包内有 `lib/tarot-assets-sources.json` 和素材说明。牌背为本地原创 SVG，中文关键词及正逆位摘要为本项目自写。

基础牌义离线可读。模型解读依据冻结牌位、牌名、方向和牌义，使用独立提示词；十张牌阵输出上限 5000 tokens，其余沿用配置上限。首份输出及取消前文字进入新版私人加密记录；普通 DSH Session 只记录操作元信息。

## 梅花易数规则（保持 v1）

固定先天八卦序数：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。除八余零按八；除六余零按六。六爻从下向上编号。

| 起卦方式 | 上卦 | 下卦 | 动爻 |
| --- | --- | --- | --- |
| 时间起卦 | 年支序数 + 农历月 + 农历日，除八取余 | 前述和 + 时支序数，除八取余 | 年支序数 + 农历月 + 农历日 + 时支序数，除六取余 |
| 三数起卦 | 第一数 A 除八取余 | 第二数 B 除八取余 | A + B + C 除六取余 |

- 年支与时支采用子 1 至亥 12；时间在点击起卦时冻结，也可手动指定。
- 默认时区 `Asia/Shanghai`；使用运行环境 ICU 的中国农历，支持公历 1900—2100 年。
- 按农历新年换年、当地零点换日；23:00 与 00:00 均属子时，23:00 不提前换日。闰月使用同一月份数字，并在页面注明「闰」。
- 互卦下卦取二三四爻，上卦取三四五爻；纯乾、纯坤从变卦取互卦。变卦只翻转动爻。
- 动爻所在的三爻卦为用，另一三爻卦为体；五行对应乾兑金、震巽木、坎水、离火、艮坤土。
- 每个数字须为 1—999,999,999 的整数。问题及补充当下信息作为解读背景，不隐式改变起卦算法。

这些是本版采用的明确约定。模型收到冻结后的卦象和过程，负责文字解读，不负责重新计算卦象。

## 本地解读人设预设

梅花与塔罗的独立系统提示词分别位于 `src/host/prompt.ts` 的 `INTERPRETATION_SYSTEM` 和 `src/host/tarot-service.ts` 的 `TAROT_INTERPRETATION_SYSTEM`；三个新模块的独立提示词位于 `src/host/method-service.ts`。它们由 Host 直接传给所选模型，并随请求写入私人加密记录；无需手动粘贴到聊天窗口。修改源码后需要重新构建并更新所用插件包，已安装的旧包不会自动读取工作区修改。

预设角色为耐心、平和的中文讲解者，面向没有易学或塔罗基础的读者。解释按「本次结果依据 → 术语的白话含义 → 与所问之事的联系」展开，先回答主要问题，再讲有利条件、阻碍、可调整的趋势和仍需现实核实的信息，最后给出 2—3 项带理由及观察反馈的小行动。梅花覆盖三卦、体用五行和动爻；塔罗按牌位、牌名、方向及本地牌义逐张解释，再梳理牌间关系。单牌不虚构多牌关系，十牌不遗漏牌位。

保留四段输出：梅花为「卦象总览、体用与变化、结合所问、今日可做之事」；塔罗为「牌阵总览、逐牌解读、牌间关系、可以尝试的行动」。梅花、单牌与三牌参考长度为 600—1000 汉字，十牌为 1200—1800 汉字，输出 token 上限沿用现有配置。象征联想与用户提供的事实分开表达，背景不足时说明条件，不编造卦爻原文、经历、他人真实想法或必然结果。

## 围绕结果多轮对话

梅花与塔罗在初始解读已有文字并结束后显示「继续聊聊这次解读」。填写追问并发送，可请模型解释术语、说明判断依据、结合补充情况或细化行动建议。每轮都携带本次冻结结果、初始解读和此前问答，沿用首次所选供应商与模型，不重起卦、不重抽牌；追问使用专用提示词，直接回答本轮问题。

追问逐字显示，可取消本轮回答；取消、超时、供应商错误或截断保留当前轮文字与状态，之后可提交新的追问。首份解读与此前回答保留。提交及生成期间禁止重复发送、重起卦、重新抽牌和插件内导航；接受取消终态后解锁。切换宿主页面或重开客户端仍可恢复问答与当前流式轮次；追问草稿在本次客户端实例内保留，提交失败不清空。另起卦或重新洗牌开始新的对话。

每条追问最多 2000 字符。完整输入（系统提示词、固定结果、初始解读和按序问答）超过 60000 字符时会明确拒绝新请求，不静默裁掉此前问答。主动发送追问会调用供应商，结束本轮、离开模块或另起一轮也可能调用所选模型提炼新增问询，按该供应商规则计费；打开输入框和查看问答不调用模型。复制结果包含固定卦象或牌阵、初始解读、按序问答和每轮状态。每轮追问及完整上下文进入私人加密记录，普通 DSH Session 只保留模块、随机请求标识、背景版本、计量、终态和稳定错误码；首版仍不提供完整历史浏览或重启恢复当前牌阵/卦象。

梅花追问 RPC 为 `/api/meihua/followup`，塔罗为 `/api/tarot/followup`，0.4 客户端 payload 为 `{id, question, expectedTurnCount, epoch}`。`expectedTurnCount` 必须等于当前已记录追问轮数，防止重复提交或过期页面追加到错误上下文。

原有梅花、塔罗路由名称与公共 core/tarot 导出保留，结果增加可选的背景使用元信息。0.4 启用共享记忆后，客户端先读取 `memory/status` 的当前 `epoch`，并将其附在两模块的私人操作请求中；锁定、清空或重新启动后须读取新代次。缺少或过期的代次会以 `MEMORY_STALE` 拒绝，防止旧页面重新提交已清除的资料；直接调用 RPC 的 0.3 客户端需要同步更新这一字段。

追问取消 RPC 使用 `{id, turnId}`，只有与当前生成轮次一致才会取消；旧页面发送已结束轮次或遗漏轮次时会拒绝，避免误停另一窗口刚开始的回答。首次解读仍兼容 `{id}` 取消请求。

## 保留范围与边界

同一插件运行期间，五模块独立维护当前结果与草稿。切换到其他宿主页面、关闭插件页面后再打开，恢复原进度；刷新后由 Host 恢复冻结结果，客户端内存草稿在本次插件实例内保留。重新起卦或洗牌仅替换该模块结果。

当前结果支持多轮追问，初始解读保持保留；没有跨次占卜的历史列表、重新生成初始解读、后台定时占卜或多模型比较。重启 DSH 后页面从空状态开始，长期留存可使用「复制结果」，新版背景、版本和私人问询记录由独立口令加密保存；旧版 Session 日志仍由 DSH 保存，不会自动迁移或删除。取消和超时通过 AbortSignal 终止当前请求；全插件同一时刻只允许一份初始解读或追问回答，不自动重试。宿主自己的导航不被拦截，离开后返回仍恢复生成状态。

文化配色跟随宿主主题服务的深浅状态，在桌面宽屏为双栏，窄窗自动堆叠；十字牌阵窄窗采用编号列表与小型位置图。遵循减少动态效果设置，隐藏页面暂停星空和洗牌动画，插件销毁时清理计时器、订阅和 Canvas。门户转场限于插件主面板，并避让 macOS 标题栏。

## 开发与验收

此仓库为插件主工作区；`dsh_clone` 仅作为结构、接口和开发工具的只读参考。正式包只包含 `lib/`、组合包 patch、README、LICENSE 和包清单。

本机可直接复用已安装的 DSH 发布版和参考仓库现有工具，避免更改参考仓库或下载依赖：

```sh
npm run prepare:local
npm run typecheck
npm run build
npm test
npm run preview
```

`prepare:local` 将已安装的发布版运行库提取到本仓库 `.local/runtime`，开发工具以符号链接只读复用。默认桌面应用资源位置为 `/Applications/DeepSeek Harness.app/Contents/Resources`，参考仓库为相邻的 `../dsh_clone`；可通过 `DSH_RESOURCES` 与 `DSH_REFERENCE` 覆盖。一般开发环境也可安装 package.json 中列明的依赖；正式 JSONL 集成测试需本机发布版提取目录。

`preview` 用官方 `dsh` 入口启动隔离的 `.local/test-home` profile，不更改正式桌面配置。打开终端输出的本地地址，选择 **「本地演示 · 模拟供应商」** 可验收首次解读、多轮上下文、流式显示、取消恢复和并发限制。可用 `DSH_DEMO_DELAY_MS` 调整模拟逐段输出间隔（默认 400 毫秒），`DSH_DEMO_SUMMARY_MODE` 选择 valid / invalid / failure / slow 摘要夹具，`DSH_PREVIEW_HOME` 指定独立测试目录。模拟摘要只验证流程与原文证据约束，不代表真实模型质量。该模拟输出与正式模型解读不同，不调用真实 API，不进入发行包。可通过 `DSH_CLI` 指定官方 CLI、`DSH_PREVIEW_PORT` 指定端口（默认 19402）。

### 提交与推送规则

`video/` 是宣传片的本地工作区（渲染产出体积大、可随时重建），不进入版本库：

- `.gitignore` 已忽略 `video/`；
- `scripts/git-hooks/pre-commit` 拒绝提交任何 `video/` 路径，并拒绝把被 `.gitignore` 忽略的新增文件强制加入提交；
- `scripts/git-hooks/pre-push` 拒绝推送任何包含 `video/` 内容的提交（含历史中曾出现过后被删除的情况）。

钩子通过仓库级配置生效，克隆后执行一次即可：

```sh
git config core.hooksPath scripts/git-hooks

```

确有必要时可用 `git commit --no-verify` / `git push --no-verify` 绕过。

## 扩展接口

门户由内置模块清单组织，当前内置 `meihua`、`tarot`、`xiaoliu`、`lenormand`、`liuyao`。`dsh-meihua/tarot` 导出牌组/牌阵类型、定义、查找与可注入测试随机源的纯洗牌函数。认证塔罗 RPC 为 `/api/tarot/{catalog,current,start,select,reveal,interpret,followup,cancel}`；未揭牌位不包含 card/orientation。原有下列梅花接口保持兼容。

`dsh-meihua/core` 导出 `DivinationRule`、`EnvironmentContributor`、`RuleRegistry`、农历换算和八卦/六十四卦推导函数。Host 提供 `ctx.meihua` 服务，扩展插件声明 `inject: ['meihua']` 后可注册规则或环境来源，并将返回的撤销函数交给自身 effect。

```js
import { lunarMoment } from 'dsh-meihua/core';
export const inject = ['meihua'];
export function apply(ctx) {
  ctx.effect(() => ctx.meihua.registerRule({
    id: 'two-numbers-time', name: '两数加时',
    fields: [
      { key: 'a', label: '第一数', min: 1, max: 999999999 },
      { key: 'b', label: '第二数', min: 1, max: 999999999 },
    ],
    calculate({ values, environment }) {
      const hour = lunarMoment(environment).hourNumber;
      return {
        upper: values.a % 8 || 8,
        lower: values.b % 8 || 8,
        movingLine: (values.a + values.b + hour) % 6 || 6,
        steps: [`两数 ${values.a}、${values.b}，时支序数 ${hour}`],
      };
    },
  }));
  ctx.effect(() => ctx.meihua.registerEnvironment('manual-extra', () => ({ note: '自定义观察' })));
}
```

扩展数字方式会自动出现在起卦方式与整数输入表单中，共用动画、卦象推导和解读流程。环境来源接收冻结的时间/时区/既有观察；返回 JSON 对象，按来源标识加入解读背景。首版不自动采集位置、天气或设备信息。
