# 0.3.0 解读结果多轮对话验收

日期：2026-10-05。工作区：`dsh-梅花易数`。适配 DSH 桌面端 `0.2.0-rc.2`。本记录对应本地构建与隔离预览，不代表正式桌面安装或真实模型联调。

## 交付行为

梅花与塔罗在初始解读结束且已有文字后显示「继续聊聊这次解读」。每轮追问沿用首份解读的模型，携带冻结结果、首份解读和全部既有问答。首次解读独立保留，追问不重起卦、不重抽牌。首份解读因失败或取消留下非空文字时，也可继续追问，上下文会明确标记未完成内容。

回答按轮次流式显示，可取消当前轮；取消、失败、超时或截断均保留已收到的文字、状态和错误。结束后可继续发出新问题。提交及生成期间锁住重复提交、重起卦、重新洗牌与插件内导航；宿主页面切换不终止生成，重新打开页面从 Host 恢复问答。每条追问最多 2000 字符，完整输入超过 60000 字符明确拒绝，不静默裁剪历史。复制结果包含初始结果、首份解读与全部问答状态。

每轮追问使用独立的标准 DSH Session，调用供应商前完整写入并 flush 系统提示词与按角色排序的上下文。首解人设保持耐心、通俗的中文阐释，追问使用专用系统提示词直接回应当前问题。
