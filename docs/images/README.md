## 运行来源与检查

- 运行方式：`DSH_PREVIEW_HOME=.local/readme-preview-home DSH_PREVIEW_PORT=19418 npm run preview`。
- 预览配置：独立的 `.local/readme-preview-home`；仅监听本机 `127.0.0.1:19418`。
- 界面构建：当前仓库 `lib/client.js`、`lib/index.js` 和 `lib/styles.css`；相关构建产物生成于 2026 年 10 月 7 日 12:05，晚于本次使用的界面源码修改时间。
- 浏览器：本机 Google Chrome `154.0.8037.99`，通过已有 Playwright 依赖执行真实点击、输入、选牌、揭牌和手动记录操作。
- 图片来源：直接截取 `.wx-hub` 元素；没有后期修图或修改 DOM 内容。
- 模型调用：**0 次**。预览中只配置了本地模拟供应商，截图过程没有点击「开始解读」或发送追问；浏览器还阻止了外部请求及解读、追问请求。
- 私人资料：只有文档明确标注的虚构示例。共享背景口令未出现在图片中，浏览器地址栏与临时访问凭据也未被截入。
- 检查结果：7 张图片已逐张查看，牌面图片均成功加载，关键结果、完整表格与页面底部内容可见；浏览器没有记录页面脚本异常。

本地复核脚本和报告保存在 `artifacts/verification-readme/`；该目录用于保留开发证据，不属于插件运行时依赖。截图完成后，临时浏览器与本次启动的预览服务均已关闭。
