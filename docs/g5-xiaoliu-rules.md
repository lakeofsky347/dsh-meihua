# G5 小六壬：固定月日时规则与对照样例

本版实现一套完整的六宫月日时起课法。计算、六位资料和原创本地释义都在 `src/xiaoliu/`，无需模型、网络或随机数。AI只解释已经冻结的本课，不更改起课结果。

## 原始资料与采用范围

2026-10-07实际阅读[《玉匣记·李淳风六壬时课》原文](https://zh.wikisource.org/w/index.php?title=玉匣記&oldid=2637999#雜占篇_李淳風六壬時課)。采用大安起正月、月上起日、日上起时的六宫循环和该篇的三月初五辰时例。来源是原书公开转录，原书署名的历史归属不作为已证实事实。

六宫按大安、留连、速喜、赤口、小吉、空亡顺序。元素/神名遵循上述篇目：木/青龙、水/玄武、火/朱雀、金/白虎、木/六合、土/勾陈。产品中的 `meaning` 与关键词由本项目原创改写成便于思考的提示；未搬入原文对疾病、官事等的确定性吉凶断语。

日期通过既有 `lunarMoment` 的完整ICU中国农历转换获得。独立日期对照使用[香港天文台2024年二月原页](https://www.hko.gov.hk/tc/gts/astron2024/files/2024cal02.pdf)与[四月原页](https://www.hko.gov.hk/tc/gts/astron2024/files/2024cal04.pdf)，已下载并渲染人工读图。

## 固定约定

| 项目 | 首版约定 |
|---|---|
| 月数 | 所选时区的农历月份1—12，不用节气月或公历月 |
| 闰月 | 同名月份取同一个数，例如闰二月仍取2；不额外进一宫 |
| 日数 | 农历初一取1、三十取30 |
| 时数 | 子至亥取1—12；子时为23:00—00:59，其余每两小时一位 |
| 日界 | 当地民用零点换日；23:00只换时辰，不提前换日期 |
| 计数 | 每段都含起点计1；月宫起初一、日宫起子时 |
| 结果 | 同时保存月、日、时三宫，以时宫为最终落宫 |
| 时间范围 | 沿用已有ICU农历的1900—2100年验证边界；不存在的当地时间拒绝 |

以上闰月和子时日界是本项目明确选定的规则，不能泛称所有传承都一致。不读取生日推算，不加年数、分钟、经度或随机数。

用零下标表示六宫时，月宫 `(month - 1) mod 6`，日宫 `(monthIndex + day - 1) mod 6`，时宫 `(dayIndex + hourNumber - 1) mod 6`。余零就是大安，界面显示一至六的宫位编号。过程文字保留每段起点和计数，用户能逐步人工核对。

## 独立人工对照

| 公历当地时间 / Asia/Shanghai | 日期来源或规则来源 | 预期月宫 → 日宫 → 时宫 |
|---|---|---|
| 2024-04-13 08:00，三月初五辰时 | 天文台四月原页确认农历；原书直接给出本例 | 速喜 → 大安 → 小吉 |
| 2024-02-10 00:00，正月初一子时 | 天文台二月原页确认初一；三段含起点各只数一步 | 大安 → 大安 → 大安 |
| 2024-02-09 23:00，十二月三十子时 | 天文台二月原页确认三十；本项目零点换日 | 空亡 → 小吉 → 小吉 |
| 2024-04-08 00:00，二月三十子时 | 天文台四月原页确认三十 | 留连 → 大安 → 大安 |
| 2024-04-09 00:00，三月初一子时 | 天文台四月原页确认初一 | 速喜 → 速喜 → 速喜 |
| 2023-03-22 00:00，闰二月初一子时 | 既有ICU闰月回归样例；按明确闰月约定计数 | 留连 → 留连 → 留连 |

例如原书例月从大安数到三月为速喜，速喜起初一依次为速喜、赤口、小吉、空亡、大安，随后大安起子时数到辰时为小吉。预期值来自原文和手算，不由 `calculateXiaoliu` 生成。

## 接口与验证

`calculateXiaoliu({ question, environment: CastEnvironment })` 返回递归冻结的 `XiaoliuResult`，包括 `input`、`lunar`、`monthPalace`、`dayPalace`、`hourPalace`、`name`、`element`、`meaning`、`steps`、`conventions`。不保留调用方可变对象。空白问题、超4000字符、无效时间与不支持年份拒绝。

`XIAOLIU_PALACES` 导出完整六宫的编号、名称、五行、神名、关键词和原创释义，可供界面直接展示。`tests/xiaoliu.test.ts`覆盖原书例、十二时辰两次循环、子初/零点、月末/初一、闰月、跨时区、深度冻结和非法输入。此证据支持本地规则正确性；模型解释质量与桌面交互由集成验收另行记录。
